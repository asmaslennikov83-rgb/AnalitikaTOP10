# Сборка 0.3.0

Запуск на хостинге: npm install, затем npm start. Файл запуска: index.js. Node.js >=22.
Переменные окружения: TELEGRAM_BOT_TOKEN, TELEGRAM_USER_IDS, WB_API_TOKEN_1, WB_API_TOKEN_2, REPORT_START.
Оба API-токена WB должны иметь доступ к категории Контент.
/subjects автоматически получает предметы из активных карточек каждого кабинета с пагинацией.
/start и /help показывают версию сборки.

Авторизация кабинета удалена. Получение сравнения с конкурентами через публичный API не подтверждено: /report сообщает об этом и не выдаёт файл с подменёнными данными. Это промежуточная сборка, не готовая выгрузка отчёта.

Образец оформления принят: отдельные файлы по предметам; пять групп фильтров вместе; блок Все фильтры; строки Всего, сумма двух кабинетов, каждый кабинет, конкуренты; показатели штуки, доля в штуках, рубли, доля в рублях, средняя цена. Перенос этого оформления пока не реализован.

Токены задаются только в переменных окружения хостинга, не в Telegram. Файл .env не требуется. Автоматическое восстановление процесса управляется хостингом.

Сборка 0.3.1: команда /check выполняет по одному диагностическому запросу сравнения и публичной воронки на кабинет. Для публичной воронки нужны права Аналитика у WB_API_TOKEN_1/2 в дополнение к Контенту. Запрос сравнения пробует обычный заголовок Authorization, без авторизации кабинета. HTTP 401/403 не является доказательством отсутствия метода. /report пока не включён. Версия отображается в /start и /help.
